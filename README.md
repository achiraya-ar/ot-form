# OT-Form

โปรแกรมเดสก์ท็อปสำหรับทำเอกสาร **ค่าตอบแทนการปฏิบัติงานนอกเวลาราชการ** ครบทั้ง 5 ไฟล์ในชุดเดียว

สร้างด้วย Tauri 2 + React + TypeScript + Vite ออกแบบหน้าจอแบบ document-first ไม่มี sidebar
เพื่อให้เอกสารแนวนอน A4 แสดงได้เต็มความกว้าง และใช้ธีมสีฟ้าพาสเทล–ทอง–ชมพูตาม `logo.svg` แบบเรียบง่าย
ปุ่มหลักใช้สีฟ้า ทองใช้เฉพาะจุดสำคัญ และพื้นหลังเป็นสีขาว/ฟ้าอ่อนเพื่อให้อ่านเอกสารได้สบายตา

## ฟีเจอร์

- หน้าเข้าสู่ระบบธีมก้อนเมฆ–เงิน–ธนบัตร–ทอง พร้อมมาสคอตจาก logo กดปุ่มเดียวเข้าใช้งาน ไม่ต้องใช้ชื่อผู้ใช้หรือรหัสผ่าน (ไม่เชื่อม HOSxP)
- สร้างชุดเอกสารแบบ 2 ขั้นตอนง่าย ๆ
  - ขั้นที่ 1 เลือกเดือน/ปี และวันที่ (วันเดียว หลายวัน ช่วงวันที่ หรือเต็มเดือน)
  - ขั้นที่ 2 เลือกพนักงานและผู้ควบคุม
  - ข้อมูลหน่วยงาน เลขเอกสาร และผู้ลงนามใช้ค่าจากหน้าตั้งค่า
- ตั้งค่าหน่วยงาน ผู้ลงนาม พนักงาน อัตราค่าตอบแทนรายคน ช่วงเวรหลายช่วง และรูปแบบเลขเอกสาร
- ทำเอกสาร 5 ไฟล์ต่อชุด
  1. คำสั่งแต่งตั้งเจ้าหน้าที่
  2. บันทึกขออนุมัติขึ้นปฏิบัติงานนอกเวลา
  3. ตารางเวร
  4. บัญชีลงเวลาปฏิบัติงาน
  5. หลักฐานการจ่ายเงินค่าตอบแทน
- จัดตารางเวรแบบปฏิทินรายเดือนต่อพนักงาน
  - เลือกพนักงานทางซ้าย แล้วคลิก เช้า/เย็น ในแต่ละวันของปฏิทิน
  - มีปุ่มเติมเร็ว เช่น อ. เช้า และ จ.–พฤ. เย็น
  - คัดลอกตารางทั้งเดือนของคนหนึ่งไปทุกคนได้
  - วันสีเทาคือวันที่ไม่ได้เลือกไว้ในชุด และแก้ไขไม่ได้
  - รองรับวันที่แต่ละคนไม่เหมือนกัน ไม่เหมารวมทุกวันจันทร์
- บันทึกการขาดงาน/เวลาจริง และให้ระบบตัดเวลาออกจากการคำนวณ
- ตารางเวรแสดงเครื่องหมาย `-` เมื่อไม่มาปฏิบัติงาน
- ใบลงเวลา: เมื่อไม่มา ช่องเวลาจะว่าง และช่องลายเซ็นทั้งสองช่องแสดง `-` แบบไม่ทำตัวหนา
- คำนวณค่าตอบแทนรายชั่วโมงตามอัตรารายคน และแปลงจำนวนเงินเป็นตัวอักษรไทย
- หน้าจอโปรแกรมใช้เลขอารบิก (Arabic numerals) ทั้งหมด
- ไฟล์ Word/Excel/PDF ทั้ง 5 ไฟล์ใช้เลขไทยตามรูปแบบเอกสารราชการ
- ส่งออก Word (.docx), Excel (.xlsx) และ PDF
- เก็บข้อมูลในเครื่อง พร้อมสำรอง/นำเข้าไฟล์ JSON
- หน้าจอหลักและหน้าทำงานถูกออกแบบใหม่ให้เรียบง่ายขึ้น ไม่มี sidebar
- หน้าทำงานต่อชุดใช้แถบความคืบหน้าแบบจุด + ปุ่มแก้ไขหลักปุ่มเดียว ลดปุ่มและขั้นตอนที่ไม่จำเป็น
- เลขที่คำสั่งเริ่มต้นเป็น `......./2569` โดยปี พ.ศ. ต่อท้ายอัตโนมัติ และให้กรอกเลขด้านหน้าเอง
- แก้ไขเอกสารที่บันทึกแล้วได้ตลอดเวลา

## การติดตั้งและรัน

ต้องมี Node.js, Rust, และ Tauri prerequisites ของระบบปฏิบัติการ

```bash
# ติดตั้ง dependency
npm install
npm --prefix app install

# โหมดพัฒนา (เว็บ)
npm run dev
# เปิด http://localhost:1420

# โหมดเดสก์ท็อป
npm run tauri:dev
```

สร้างชุดติดตั้ง:

```bash
npm run tauri:build
```

ไฟล์ติดตั้งจะอยู่ใต้ `src-tauri/target/release/bundle`

## หมายเหตุ

- ข้อมูลเก็บใน `localStorage` ของ WebView ในเครื่องนี้
- การสำรองข้อมูลจะได้ไฟล์ JSON ที่มีทั้งค่าตั้งค่าและชุดเอกสารทั้งหมด
- ไฟล์ Word/Excel สร้างจากข้อมูลล่าสุด ไม่ใช่การแก้ไฟล์ต้นแบบโดยตรง
- ฟอนต์ในเอกสารใช้ TH SarabunPSK สำหรับ Word และ Sarabun สำหรับหน้าจอ/PDF

## สิ่งที่ควรทราบ

- ข้อมูลชุดเอกสารเก็บใน `localStorage` ของแอปบนเครื่องนี้ แนะนำให้กด **สำรองข้อมูล** เป็นระยะ
- หลังสร้างชุดแล้ว การเปลี่ยนเดือน/วันที่ทั้งชุดควรสร้างชุดใหม่ เพื่อไม่ให้ตารางเวรและใบลงเวลาเดิมขัดกัน
  แต่สามารถแก้ไขเลขเอกสาร หน่วยงาน ผู้ลงนาม ตารางเวร เวลามา–กลับ และอัตราค่าตอบแทนของชุดเดิมได้
- ไฟล์ Word/Excel สร้างจากข้อมูลล่าสุด (ไม่ใช่การแก้ไฟล์ `.docx`/`.xls` ต้นฉบับโดยตรง)
- PDF สร้างจากหน้าตัวอย่างเอกสาร (เป็นภาพคุณภาพสูง ไม่แก้ไขข้อความ)
- ในแอปเดสก์ท็อป ปุ่ม **พิมพ์** จะสร้าง PDF ให้ก่อน เพื่อให้เปิดสั่งพิมพ์ได้จากโปรแกรมอ่าน PDF
- หน้าจอใช้เลขอารบิกตามรูปแบบที่ตั้งค่า (เลขที่คำสั่งเริ่มต้น `......./2569` และเลขที่บันทึก `ลบ0033.302/พิเศษ`)
  แต่ในไฟล์เอกสารจะแสดงเลขไทย เช่น `ลบ๐๐๓๓.๓๐๒/พิเศษ` พร้อมวันที่ เวลา จำนวนวัน และจำนวนเงินเป็นเลขไทย
